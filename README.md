A complete, beginner-friendly machine-learning project: explore the data, train a Linear Regression model, evaluate it (MAE, RMSE, R²), write a short PDF report, and use the model through a secure web app.

**Task deliverables covered**
1. `task1_ml_linear_regression.ipynb` – notebook with code, plots and comments
2. A 2–4 page PDF report – generated by the notebook (`Task1_Linear_Regression_Report.pdf`)
3. Saved model pickles, a command-line predictor and a web UI

## Quick start (about 5 minutes)
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 1) Create your settings file (random SECRET_KEY, local development mode)
python setup_env.py

# 2) Train on the REAL dataset (needs internet once; the data is then cached)
python train.py

# 3) Run the web app
python app.py                   # open http://127.0.0.1:5000
```
> If you skip step 2, the app trains automatically on first start. If the dataset cannot be downloaded it falls back to a **synthetic demo model** and shows a red "Demo model" warning in the page. Run `python train.py` with internet access to replace it with the real model.

## The notebook and the PDF report
```bash
jupyter notebook task1_ml_linear_regression.ipynb     # Kernel -> Restart & Run All
```
It creates `figures/`, `models/*.pkl`, `results.json` and **`Task1_Linear_Regression_Report.pdf`** (every number in the report comes from your run). Save the notebook *with outputs* before pushing it to GitHub so the plots show up.

## What the model does
* Data: California Housing (20,640 census block groups, 1990). Target `MedHouseVal` is in units of $100,000.
* **Baseline:** `StandardScaler` + `LinearRegression` inside a scikit-learn `Pipeline` (80/20 split, `random_state=42`).
* **Improved:** `RidgeCV` + engineered features (ratios, log transforms, distance to LA / SF / San Diego / San Jose).
* Metrics are computed on the held-out test set and shown in the app and in `models/metrics.json`. For the plain baseline on this dataset, results typically land around R² ≈ 0.6 and an error of roughly $50,000; your exact numbers come from your own run.

## API reference
All writes need the `X-CSRF-Token` header (get it from `GET /api/session`).

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/session` | current user and CSRF token |
| GET | `/api/meta` | feature ranges, model metrics, demo flag |
| POST | `/api/predict` | JSON with the 8 features (+ optional `"model": "baseline"\|"improved"`) → price |
| POST | `/api/predict-batch` | multipart CSV upload (columns = the 8 features) |
| POST | `/api/register`, `/api/login`, `/api/logout` | accounts |
| GET / DELETE | `/api/history` | your saved predictions |
| POST | `/api/feedback` | send feedback |
| GET | `/api/admin/stats` | admin only |

Make an admin from the server command line: `python app.py make-admin you@example.com`.

Command-line prediction (no server needed): `python predict.py --MedInc 5 --Latitude 37.8 --Longitude -122.3`

## Tests
```bash
python tests/test_app.py       # 58 checks: predictions, validation, CSV upload, CSRF, auth, isolation, injection, headers, rate limits
```
The tests use a temporary database and model, so they never touch your real data and need no internet. For the optional browser test: `pip install playwright && playwright install chromium`, start the app with `PORT=5055`, then `python tests/e2e_browser.py`.

## Deploy
```bash
APP_ENV=production gunicorn -w 2 -b 0.0.0.0:8000 app:app     # behind HTTPS (e.g. Nginx, Render, Railway)
```
Set `SECRET_KEY` and `ALLOWED_ORIGINS` as environment variables on the host. Do not commit `.env`. Read `docs/SECURITY_CHECKLIST.md` before going live. A `Dockerfile` and `Procfile` are included (`docker build -t hpp . && docker run -e SECRET_KEY=<long random> -p 8000:8000 hpp`). The Docker setup has not been tested yet; the Python app itself has.

## Troubleshooting
| Problem | Fix |
|---|---|
| `SECRET_KEY missing or shorter than 32 chars` | run `python setup_env.py` |
| Predictions fail after upgrading scikit-learn | run `python train.py` to retrain (model files depend on the library version) |
| Login works but you are immediately signed out on localhost | set `APP_ENV=development` (the cookie is HTTPS-only in production mode) |
| Red "Demo model" warning | run `python train.py` with internet access |
| `ModuleNotFoundError: housing_utils` while loading a model | run Python from the project folder |
| Port already in use | set `PORT=5001` in `.env` |
