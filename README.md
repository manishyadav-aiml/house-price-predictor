## ⚙️ Quick Start (About 5 Minutes)

### Prerequisites

- Python 3.11 or 3.12
- Git
- pip
- Internet connection for downloading the dataset

### 1. Clone the Repository

```bash
git clone https://github.com/manishyadav-aiml/house-price-predictor.git
```

### 2. Navigate to the Project Directory

```bash
cd house-price-predictor
```

### 3. Create a Virtual Environment

**Windows:**

```powershell
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
python -m venv .venv
source .venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Environment Variables

```bash
python setup_env.py
```

This creates your local `.env` file with a randomly generated `SECRET_KEY` and development configuration.

### 6. Train the Machine Learning Models

```bash
python train.py
```

The training script downloads and processes the California Housing dataset, trains both models, evaluates their performance, and saves the trained model files.

### 7. Run the Web Application

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:5000
```

> **Note:** If you skip the training step, the application can train automatically on first start. If the dataset cannot be downloaded, it falls back to a **synthetic demo model** and displays a red "Demo model" warning. Run `python train.py` with internet access to train using the real dataset.

## 🧠 What the Model Does

### Dataset

The project uses the California Housing dataset.

- 20,640 census block groups.
- California housing data from the 1990 census.
- 8 input features.
- Target variable: `MedHouseVal`.
- Target values are expressed in units of $100,000.

### Input Features

| Feature | Description |
|---|---|
| `MedInc` | Median income |
| `HouseAge` | Median house age |
| `AveRooms` | Average number of rooms |
| `AveBedrms` | Average number of bedrooms |
| `Population` | Block population |
| `AveOccup` | Average household occupancy |
| `Latitude` | Geographic latitude |
| `Longitude` | Geographic longitude |

### Baseline Model

The baseline model uses:

- `StandardScaler`
- `LinearRegression`
- Scikit-learn `Pipeline`
- 80/20 train-test split
- `random_state=42`

### Improved Model

The improved model uses:

- `RidgeCV`
- Feature engineering
- Ratio-based features
- Log transformations
- Geographic distance features for Los Angeles, San Francisco, San Diego and San Jose.

### Model Evaluation

The models are evaluated using:

| Metric | Purpose |
|---|---|
| MAE | Measures average absolute prediction error |
| RMSE | Measures the square root of average squared prediction error |
| R² | Measures how much target variance is explained by the model |

Metrics are calculated on the held-out test set and displayed in the application and `models/metrics.json`.

## 🔌 API Reference

All write operations require the `X-CSRF-Token` header. Obtain the token from `GET /api/session`.

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/session` | Current user and CSRF token |
| GET | `/api/meta` | Feature ranges, model metrics and demo flag |
| POST | `/api/predict` | Generate a house price prediction |
| POST | `/api/predict-batch` | Upload a CSV file for batch predictions |
| POST | `/api/register` | Register a new user |
| POST | `/api/login` | Authenticate a user |
| POST | `/api/logout` | Log out a user |
| GET | `/api/history` | Retrieve saved predictions |
| DELETE | `/api/history` | Delete prediction history |
| POST | `/api/feedback` | Submit feedback |
| GET | `/api/admin/stats` | Retrieve administrator statistics |

### Example Prediction Request

```json
{
  "MedInc": 5,
  "HouseAge": 20,
  "AveRooms": 6,
  "AveBedrms": 1,
  "Population": 1000,
  "AveOccup": 3,
  "Latitude": 37.8,
  "Longitude": -122.3,
  "model": "improved"
}
```

The request must include the required CSRF header.

### Create an Administrator

Run the following command from the project directory:

```bash
python app.py make-admin you@example.com
```

### Command-Line Prediction

Predictions can also be generated without starting the web server:

```bash
python predict.py --MedInc 5 --Latitude 37.8 --Longitude -122.3
```

## 🚀 Deploy

### Live Deployment

The application is deployed on **Vercel**.

**Production URL:**

👉 https://house-price-predictor-blond.vercel.app/

### Production-Style Server Command

For a compatible server environment:

```bash
APP_ENV=production gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

Set the following environment variables on the hosting platform:

- `SECRET_KEY`
- `APP_ENV`
- `DATABASE_PATH`
- `ALLOWED_ORIGINS`

Do not commit `.env` to GitHub.

Read `docs/SECURITY_CHECKLIST.md` before deploying.

### Docker

A `Dockerfile` and `Procfile` are included in the repository.

**Note:** The Docker setup has not been tested yet. The Python application itself has been tested.

### Deployment Limitation

The current Vercel configuration uses `/tmp/app.db` for SQLite storage.

Vercel's temporary filesystem is not guaranteed to persist between executions or deployments. Therefore, user accounts and prediction history should not be considered permanently stored in the current deployment.

For persistent production storage, connect the application to a managed database.

## 🔧 Troubleshooting

| Problem | Solution |
|---|---|
| `SECRET_KEY missing or shorter than 32 chars` | Run `python setup_env.py`. |
| Predictions fail after upgrading scikit-learn | Run `python train.py` to retrain the models. |
| Login works but you are immediately signed out on localhost | Set `APP_ENV=development` because the cookie is HTTPS-only in production mode. |
| Red "Demo model" warning | Run `python train.py` with internet access. |
| `ModuleNotFoundError: housing_utils` while loading a model | Run Python from the project directory. |
| Port already in use | Set `PORT=5001` in `.env`. |

## ⚠️ Limitations

- Uses 1990 California census data.
- Predictions represent census block-group averages, not individual houses.
- The original target values are capped at $500,000.
- Model performance depends on the quality and limitations of the dataset.
- This is a learning project, not a professional property valuation tool.
- The current Vercel SQLite database uses temporary storage and does not guarantee persistence.
- If the application uses the synthetic demo model, its predictions and metrics should not be presented as real-dataset model results.
