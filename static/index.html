FAQ

How accurate is it?

Accuracy figures appear once the model has loaded.

What do the inputs mean?

They describe a census block group: median income (in $10,000s), average house age, rooms, bedrooms, population, occupants per household and the location.

What is the improved model?

It adds engineered features (ratios, log transforms and distance to big cities) and Ridge regularisation. It is usually more accurate than the plain baseline.

Can I use this to value a real house?

No. The data is from 1990 and describes neighbourhood averages. Treat the result as a learning demo, not a valuation.

Is my data stored?

Predictions are only saved if you are signed in, and only you can see them. Your password is stored as a salted hash.
