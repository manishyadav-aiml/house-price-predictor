# Code of Conduct

Be kind, respectful and constructive. We want this project to be a welcoming place for learners of every level.

**Expected:** helpful feedback, patience with beginners, respect for different opinions and backgrounds.
**Not acceptable:** harassment, insults, discrimination, personal attacks, or sharing other people's private information.

Maintainers may remove comments, issues or contributions that break these rules, and may block repeat offenders. To report a problem, contact the maintainer through the repository's issue tracker or profile.
